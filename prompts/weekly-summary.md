# 給網頁版 Claude 的週總結提示詞

把下面整段複製給網頁版 Claude，再附上該週的群組截圖或文字。
將它的回覆存成 `inbox/weeks/<週一日期>.txt`（例如 `inbox/weeks/2026-10-19.txt`），之後跟 Claude Code 說「整理 inbox」即可。

---

請幫我整理這一週（週一到週日）群組老大的教學內容，**嚴格依照以下格式輸出**，不要加入其他段落：

```
週期：YYYY-MM-DD ~ YYYY-MM-DD
標題：（一句話總結本週主軸，20 字內）
摘要：（2–3 句，本週最重要的觀念與盤勢判斷）
主題：（從這些挑選：產業、技術、心態、個股、大盤總經、操作紀錄，可複選，用頓號分隔）
個股：（本週討論到的個股，格式「代號 名稱」，用頓號分隔；沒有則寫「無」）

【分段重點】
## （分段標題，例如：技術）
- 重點
- 重點
## （分段標題，例如：產業）
- 重點

老大金句：（本週最具代表性的一句原話；沒有則寫「無」）
```

注意：
- 只整理老大的教學，不要納入其他成員的閒聊。
- 重點用短句，每點 30 字內。
- 個股代號不確定時，寫名稱並在後面加「(代號待確認)」。
